# Agent workflow

Repo: [ZhannaM85/charger-shelf](https://github.com/ZhannaM85/charger-shelf). Push commits directly to `main`. Do not open pull requests unless asked.

**Commit author:** `Zhanna M <zhanna.myshkovskaya@gmail.com>`.

## Queue

Work one open issue at a time from [`docs/issues-priority.md`](./issues-priority.md), top to bottom.

## After you ship

Leave the issue **open**. Add the `validation` label. Comment with what changed and how to check it. Do not close the issue until Zhanna confirms.

## When Zhanna confirms (lean close)

Only after she confirms. One commit per issue:

1. Comment on the issue.
2. Keep the `validation` label.
3. Close the issue.
4. Move the row from `docs/issues-priority.md` to [`docs/issues-priority-archive/`](./issues-priority-archive/README.md).

## Code

- Stack: Vite + React + TypeScript + Tailwind v4. Keep the app to 1–2 screens.
- Source files stay at or under 500 lines (`eslint` `max-lines`). See [#6](https://github.com/ZhannaM85/charger-shelf/issues/6).

## Quiet mid-queue

No status spam between items. When the queue still has open work, continue to the next queued item.
